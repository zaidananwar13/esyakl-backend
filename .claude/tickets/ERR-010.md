# Ticket ERR-010: Legacy Eloquent Models Reference Non-Existent Database Tables

## Ticket Information
- **Ticket ID**: ERR-010
- **Module / Feature**: Data Layer / Eloquent Models
- **Location**: `app/Models/`, `app/Services/ClassService.php`, `app/Services/SyllabusService.php`, `app/helper.php`
- **Status**: Open / Backlogged
- **Date Created**: 2026-11-18
- **Severity**: Low / Technical Debt

---

## Issue Description
Audit integritas model Eloquent terhadap database PostgreSQL live (`arabic_go`) menemukan 6 model Eloquent yang mereferensikan tabel yang sudah tidak ada di basis data:

1. `App\Models\Discussion` (`protected $table = 'discussions'`)
2. `App\Models\Instansi` (`protected $table = 'instansi'`)
3. `App\Models\Kelas_User` (`protected $table = 'kelas_user'`)
4. `App\Models\KelasHistory` (`protected $table = 'kelas_history'`)
5. `App\Models\SilabusChecker` (`protected $table = 'silabus_checker'`)
6. `App\Models\Sub_Kategori_Silabus` (`protected $table = 'sub_kategori_silabus'`)

Jika ada kode atau endpoint yang mengeksekusi query pada model-model ini, PostgreSQL akan melempar fatal exception:
`SQLSTATE[42P01]: Undefined table: 7 ERROR: relation "..." does not exist`.

---

## Root Cause Analysis
Sistem mengalami evolusi skema dari penamaan bahasa Indonesia (`kelas_user`, `sub_kategori_silabus`, `silabus_checker`, `kelas_history`) ke skema standar modern (`class_student`, `syllabus`, `syllabus_student`).

Model-model baru sudah dibuat dan digunakan oleh antarmuka frontend saat ini:
- `ClassStudent` menggantikan `Kelas_User`.
- `Syllabus` menggantikan `Sub_Kategori_Silabus`.
- `SyllabusStudent` menggantikan `SilabusChecker` dan `KelasHistory`.
- `ClassDiscussion` menggantikan `Discussion`.

Namun, file model lama dan beberapa method uncalled di `ClassService.php`, `SyllabusService.php`, dan `app/helper.php` belum dibersihkan.

---

## Remediation Plan
1. **Model Orphan Tanpa Referensi**:
   - `Discussion`: Beri anotasi `@deprecated` atau hapus file model (pastikan tidak ada dependensi).
   - `Instansi`: Hapus atau beri anotasi `@deprecated`.
   - `Kelas_User`: Beri anotasi `@deprecated`.
2. **Method & Service Uncalled**:
   - `app/helper.php`: Method `checkSilabusAccess` dan `checkSilabusAccessUser` hanya digunakan di `SyllabusService.php`.
   - `app/Services/SyllabusService.php`: Layanan API v2 lama yang tidak lagi dipanggil oleh Frontend Sapper (Frontend memanggil `ClassroomService` dan `FEAuthController`). Tandai kelas ini sebagai `@deprecated`.
   - `app/Services/ClassService.php`: Method `updateClassHistory()` mereferensikan `KelasHistory` dan `Sub_Kategori_Silabus`. Method ini tidak memiliki caller di routing aktif. Hapus atau refaktor method ini.

---

## Acceptance Criteria
- Seluruh model di `app/Models` terverifikasi memiliki tabel database yang valid.
- Tidak ada panggilan kode aktif yang memicu `relation does not exist` di PostgreSQL.
