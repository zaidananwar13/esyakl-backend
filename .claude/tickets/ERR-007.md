# Ticket ERR-007: Modul Pembelajaran Chapter 14 'null' & Upload Proyek Akhir Error

## Ticket Information
- **Ticket ID**: ERR-007
- **Related Tickets**: ERR-001, ERR-002, ERR-003, ERR-004, ERR-005
- **Module / Feature**: Modul Pembelajaran (`/classroom`) & Proyek Akhir (`/project/submit`)
- **Class**: Final Project - Nahwu Class - Beginner (`id_class = 3`)
- **Status**: Resolved
- **Date**: 2026-11-16

---

## Issue Description
1. **Issue 1 (Chapter 14 'null')**:
   - Pada halaman Modul Pembelajaran kelas *Final Project - Nahwu Class - Beginner*, Chapter 14 menampilkan teks `'null'` pada nama chapter, sub-item, dan kuis (`'Quiz: null'`).
   - Data materi tidak dapat dimuat dari backend.
2. **Issue 2 (Gagal Upload Tugas PDF)**:
   - Pesan error modal *"Oops, there is an error, please try again!"* muncul saat user mengunggah berkas PDF tugas proyek akhir.

---

## Root Cause Analysis

### Issue 1: Chapter 14 Bernilai 'null'
- Pada tabel database `syllabus`, terdapat baris dengan `id_syllabus = 112`, `id_class = 3`, `order_number = 14` yang memiliki `title = NULL` dan `content = NULL` (draft kosong / anomali baris tanpa judul).
- Method `ClassroomService::getMaterialsWithQuizzes()` mengambil seluruh baris pada `syllabus` hanya berdasarkan `id_class = 3` tanpa memeriksa apakah judul materi valid/berisi (`whereNotNull('title')`).
- Akibatnya:
  - Backend mengirimkan objek syllabus dengan `title: null` dan `quizData: { title: null, ... }`.
  - Frontend Vue/Nuxt menampilkan nama chapter sebagai `'null'`, sub-item tidak dapat diparsing, dan judul kuis ditampilkan sebagai `'Quiz: null'`.
  - Pada `ClassroomService::getClassProgress()`, `$lastSyllabus` mengambil baris dengan `order_number` tertinggi yaitu 14. Sehingga pembagi progres menjadi 14 padahal materi riil hanya 13, menyebabkan progres siswa tidak pernah bisa mencapai status *completed* (100%).

### Issue 2: Gagal Upload Tugas PDF
- Endpoint `/project/submit` sebelumnya mengembalikan format respons JSON modern `{code: 200, ...}` tanpa properti `{status: 200}`.
- Script frontend legacy secara eksplisit mengecek `response.data.status === 200`. Karena properti `status` undefined, frontend masuk ke blok error dan menampilkan modal fallback *"Oops, there is an error, please try again!"*. Masalah ini telah diatasi pada ticket ERR-001 (commit `7ed7a6a`).

---

## Solution & Implementation Details

Pendekatan yang diambil adalah **Backend Defensive Filtering** (low-risk & zero side-effects):
Menyaring baris silabus yang tidak memiliki judul (`title IS NOT NULL AND title != ''`) di level query service dan repository. Pendekatan ini tidak menghapus record secara destruktif dari database (menghindari risiko Foreign Key constraint / data loss), serta secara permanen mencegah munculnya chapter kosong di masa depan baik pada kelas ini maupun kelas lainnya.

### 1. `app/Services/ClassroomService.php`
- Pada `getMaterialsWithQuizzes()`:
  - Menambahkan filter `->whereNotNull('title')->where('title', '!=', '')`.
  - Menghilangkan chapter kosong dari daftar materi yang dikirim ke frontend.
- Pada `getClassProgress()`:
  - Menambahkan filter `->whereNotNull('title')->where('title', '!=', '')` saat mencari `$lastSyllabus`.
  - Menghitung total materi pembelajaran yang valid (13 chapter) sehingga progres siswa dapat mencapai status `completed` saat menyelesaikan chapter 13.

### 2. `app/Services/ClassService.php`
- Pada method `all()`:
  - Menghitung `langkah` hanya untuk silabus dengan judul valid (`whereNotNull('title')->where('title', '!=', '')`).
- Pada method `enrollClass()`:
  - Mencari `$firstSyllabus` dengan judul valid.
- Pada method `getClassSyllabus()`:
  - Menambahkan filter `whereNotNull('title')->where('title', '!=', '')`.

### 3. `app/Repositories/Eloquent/ClassRepository.php`
- Pada `getSyllabus()`:
  - Menambahkan filter `whereNotNull('title')->where('title', '!=', '')`.

### 4. `app/Services/MyClassService.php` & `app/Services/UserService.php`
- Menambahkan filter `whereNotNull('title')->where('title', '!=', '')` saat menghitung silabus terakhir (`lastSyllabus` / `syls`) untuk progress kelas pada profil siswa.

### 5. `app/Services/AuthorizerService.php`
- Menambahkan filter `whereNotNull('title')->where('title', '!=', '')` pada `unlockMaterial()`.

### 6. `app/Models/Syllabus.php`
- Menambahkan query scope helper `scopeValid($query)` untuk standarisasi query silabus yang valid.
