# Ticket ERR-006: Fitur Giving Harakat & Analisis I'rab dengan AI

## Ticket Information
- **Ticket ID**: ERR-006
- **Module / Feature**: Giving Harakat & Nahwu Analysis (`/giving-harakat`)
- **Components**:
  - Frontend: `src/components/Giving-harakat-content.svelte`, `src/api/ApiController.js`
  - Backend: `app/Http/Controllers/API/HarakatController.php`, `app/Services/HarakatService.php`
- **Status**: Resolved
- **Date**: 2026-11-17

---

## Issue Description
1. Pada menu **Giving Harakat** di frontend `arabic-go.com`:
   - Pengguna memasukkan kalimat bahasa Arab gundul (tanpa harakat), namun kolom *With Harakat* dan tabel *I'rab Explanation and Translate* tidak menampilkan hasil (kosong / gagal memuat data).
2. Endpoint yang dipanggil oleh frontend adalah `https://dev.arabic-go.com/api/get/all/<teks>`, yang merupakan server/layanan lawas yang sudah dinonaktifkan (dead link).
3. Backend aktif Laravel 13 (`esyakl-backend`) sebelumnya belum memiliki controller, route, maupun service AI untuk pemrosesan tashkeel (pemberian harakat) dan analisis kaidah I'rab secara dinamis.

---

## Root Cause Analysis
1. **Broken External API Endpoint**:
   - `src/api/ApiController.js` memanggil `devUrl = "https://dev.arabic-go.com/api/get/all/"`.
   - Domain `dev.arabic-go.com` sudah tidak aktif lagi, sehingga seluruh request harakat gagal tanpa fallback.
2. **Missing Backend Implementation**:
   - Backend baru Laravel 13 belum mengimplementasikan endpoint vocalization bahasa Arab.
   - Frontend mengekspektasikan data berupa teks lengkap berharakat (`response.data.text`) dan array objek tabel Nahwu (`response.data.aroef`) dengan atribut: `arab`, `jenis`, `hukum`, `tanda`, `penjelasan`, dan `arti`.

---

## Solution & Implementation Details

### 1. Backend (`esyakl-backend`)
- **`app/Services/HarakatService.php`**:
  - Mengintegrasikan LLM Google Gemini dengan mekanisme **Multi-Model Cascade Fallback** (`gemini-3.5-flash-lite` -> `gemini-3.1-flash-lite` -> `gemini-3.5-flash`). Jika salah satu model mengalami lonjakan traffic (HTTP 503 high demand), sistem otomatis beralih ke model cadangan tanpa kegagalan di sisi pengguna.
  - Opsi fallback multi-provider: mendukung Groq (Llama 3.3 70B) dan OpenAI.
  - Menghasilkan format JSON terstruktur yang memuat teks berharakat (`text`) dan rincian tabel analisis I'rab (`aroef`).
  - Mengimplementasikan caching (`Cache::remember`) selama 7 hari berdasarkan teks dan bahasa (respons cache ~1 ms), menghemat kuota token dan mempercepat respons untuk teks yang sama.
  - Validasi panjang karakter (maksimal 1000 karakter) dan penanganan sanitasi teks Arab.
- **`app/Http/Controllers/API/HarakatController.php`**:
  - Endpoint `POST /api/harakat/vocalize` dan `POST /harakat/vocalize` yang mengembalikan format JSON standar serta properti top-level untuk kompatibilitas frontend (`text`, `aroef`, dan `data`).
  - Handler legacy `vocalizeLegacy` untuk rute `GET|POST /api/get/all/{text?}`.
- **Proteksi & Keamanan (`app/Providers/RouteServiceProvider.php`)**:
  - Rate limiting `throttle:harakat` dibatasi 20 request per menit per IP untuk mencegah abuse kuota.
- **Konfigurasi (`config/services.php`)**:
  - Menambahkan konfigurasi provider `gemini` (`api_key` dan `model`) dari `.env`.

### 2. Frontend (`arabic-go.com`)
- **`src/api/ApiController.js`**:
  - Memperbarui fungsi `HarakatController(text, lang)` agar mengirimkan request HTTP `POST` ke `{activeUrl}harakat/vocalize` dengan payload `{ text, lang }`.
  - Deteksi URL cerdas: otomatis mengarah ke `http://esyakl-backend.test/` saat berada di lingkungan dev lokal (`localhost`, `127.0.0.1`, `.test`).
- **`src/components/Giving-harakat-content.svelte`**:
  - Menambahkan **Tombol Submit ("Beri Harakat")**: request hanya dikirim saat user mengklik tombol atau menekan `Ctrl+Enter`, mencegah lonjakan request saat mengetik.
  - Menghapus pemanggilan otomatis (*auto-debounce timeout 1 detik saat keyup*).
  - Menghapus seluruh frasa *"with AI"* / *"dengan AI"*, diganti dengan deskripsi natural (*"Sedang menganalisis nahwu & memberi harakat..."*).
  - Menambahkan state `isLoading` dan penanganan SweetAlert error handling jika terjadi kendala jaringan/kuota.
